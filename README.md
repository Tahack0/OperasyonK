# OperasyonK

Unity 6 ile geliştirilen bir FPS oyunu projesi. Derleme ayarlarında ana menü, eğitim bölümü ve köy sahnesi bulunur.

## Projeyi açma

1. Git LFS kurulu bir ortamda depoyu klonla ve proje dizininde `git lfs pull` çalıştır.
2. Proje klasörünü Unity Hub’a ekle ve **6000.0.31f1** editörüyle aç.
3. Unity paketleri ve varlıkları içe aktardıktan sonra `Assets/Scenes/MainMenu/Demo1.unity` sahnesini aç.

Sahnelerde kullanılan örnek paketler ve bunların Unity `.meta` dosyaları kaynak ağacında korunur. Unity önbelleği, kullanıcı ayarları ve derleme çıktıları yerelde oluşturulur.
